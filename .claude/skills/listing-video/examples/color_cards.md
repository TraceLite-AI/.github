# 两张色卡（从原画布里抄录）

原画布把这两张色卡做成图片，连到视频节点上，提示词里写"光线参考 @外景色卡，下午四点的暖光"。
没有色卡图片时，把下面的色值和配比直接写进提示词，效果一样（实测可用）。

## 外景：午后光线色卡

由亮至暖，从受光暖白过渡到长影褐。午后 15:00–16:00，太阳高度 35°–45°。

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 暖白墙 | #FFF3E1 | 受光墙 / 高光底 |
| 蜜日光 | #F7CB7E | 直射阳光 / 暖高光 |
| 麦秆金 | #E0A94F | 干草 / 暖材质受光 |
| 天光蓝 | #92B8D8 | 阴影补光 / 唯一冷色 |
| 琥珀木 | #CB8C3B | 木作 / 石材受光 |
| 赭石棕 | #9C6034 | 暗部过渡 / 背光面 |
| 长影褐 | #6F4F36 | 长影 / 深暗部 |
| 林荫绿 | #6C7A4A | 树冠 / 环境绿 |

搭配公式：暖光 55% + 材料本色 30% + 冷影 15%。暖光靠冷影托底才最有体积。

## 内景：室内暖阳色调色卡

由柔和的暖白基底，过渡到强烈的琥珀金日光，最后以冷调的阴影收尾。午后 15:00–16:30，强烈直射光与漫反射。

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 暖白墙 | #F5F0E6 | 受光墙面 / 高光基底 |
| 蜜日光 | #F2C879 | 直射阳光 / 地板高光 |
| 琥珀木 | #C78A3E | 实木家具 / 皮质受光 |
| 赭石棕 | #A35A30 | 皮质暗部 / 木柜阴影 |
| 长影褐 | #63432C | 门缝阴影 / 暗部过渡 |
| 天光蓝 | #8AA9C1 | 窗外天空 / 冷色阴影 |
| 林荫绿 | #6B7A48 | 窗外树叶 / 环境点缀 |

搭配公式：暖光 60% + 原木/暖白底色 25% + 冷色阴影 15%。色温 3000K–3500K 是关键。
