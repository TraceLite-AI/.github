# Listing Video（房源视频）制作法

这套方法从一个 Shotlab 画布的实拍项目里拆出来，里面做了约 10 条美国房源视频。

一条 listing video 其实只由**两种片段**交替拼成：

- **A. 经纪人出镜片段**：经纪人站在房子里对着镜头说话。用在开场、重点卖点、结尾。
- **B. 空镜片段**：没有人，只拍房子，配经纪人的画外音或不配音。

**硬性要求：经纪人出镜的时间要占全片的一半左右（不低于 50%）。** 算法见第三节。

做法的核心是：**房源照片直接当场景参考图，一张照片拆成 2–3 个镜头；经纪人用一张定妆图和一段录音"放进"照片里。**

## 一、要准备的素材

| 素材 | 要求 |
|---|---|
| 房源照片 | 每个空间 1–3 张，高清。按空间起名（主卧、浴室、泳池、后院、车库…），方便引用 |
| **优化帧** | 每张房源照片先做一遍光影色彩优化（见"二点五"），**喂给视频的是优化后的图，不是原始照片** |
| 色卡 | 外景、内景各一张，写明色值和配比，用来统一全片光线和色调（见 `examples/color_cards.md`） |
| 经纪人定妆图 | **三视图 + 脸部特写**：正面、侧面、背面全身，加一张头肩特写，灰底，服装固定。全片只用这一张（见"二点六"） |
| 经纪人声音 | 经纪人本人念的整条旁白录音；没有整条录音时用声音克隆（见"二点七"） |
| 标记图（按需） | 在照片上用红色涂出"人站哪儿"或"镜头走哪条线" |
| 裁剪图（按需） | 把照片里要特写的局部裁出来 |

## 二、制作流程

1. **写旁白并切段**。整条旁白按房子动线切成 6–8 段，每段 5–15 秒，按顺序编号命名。原项目的切法：
   `1.开头外景 → 2.进门 → 3.室内设施 → 4.主卧浴室衣帽间 → 5.客房/游戏厅 → 6.后院泳池车库 → 7.结尾`
2. **每段配照片，并先做优化帧**。这段旁白说到哪个空间，就连哪几张照片；每张照片先按"二点五"出几个光影色彩优化的候选，**由用户选定**后再往下走。
3. **安排人和空镜的比例**。人物出镜时间要到全片一半：不只是开场和结尾，**每个空间都让经纪人出镜讲一句**，再切空镜补画面。排完用分段表算一遍占比（见第三节）。
4. **写分镜提示词，生成**。一个节点出 4–15 秒，里面按秒数分镜头。
5. **反复生成挑最好的**。原项目平均每段跑近 5 次。不满意就复制节点、只改一处再跑。
6. **剪辑**。导出片段按编号拼接，后期加字幕、音乐、片尾联系方式。

## 二点五、优化帧：先把照片的光影和色彩做好

**这是整套方法里最容易漏、但最影响质感的一步。** 原始房源照片通常是正午平光、颜色发灰；原画布里连到视频节点上的场景图，全部是优化过的版本：午后暖阳从窗户斜射进来，地上有窗格光斑和长影子，对比度强。视频模型会原样继承参考图的光，所以**图不好，视频怎么写提示词都救不回来。**

对比原画布里同一间主卧的两张图：原始照片墙面均匀发白、没有影子；优化帧里阳光打在床和地毯上，窗外树叶透着金光。画布里还能看到同一场景存了几版不同亮度的优化帧（如"衣帽间""衣帽间弱光线""修改2"），说明这一步也是反复调出来的。

### 怎么做

用图片模型做"图生图"，把原始照片当参考图，只改光线和色调：

```
对图片1做光影和色彩优化，只改光线和色调，其他一律不变。
【不能改】房间结构、家具、摆设、窗外景物、相机机位、视角和构图全部和图片1完全一致，
不增加也不减少任何物品。
【光线】改成下午15:00–16:30的直射暖阳：阳光从窗户斜射进来，在地板、地毯和床上投下清晰的
窗格光斑和长影子，受光的墙面有柔和的暖色漫反射。室内灯具不要更亮，主光源只有窗外的太阳。
【色调】色温3000K–3500K。配比：暖光约60%，原木和暖白底色约25%，冷色阴影约15%。
受光墙面暖白 #F5F0E6，直射阳光蜜金色 #F2C879，实木受光琥珀色 #C78A3E，木柜阴影赭石棕 #A35A30，
暗部长影褐 #63432C，阴影里带一点天光蓝 #8AA9C1，窗外树叶林荫绿 #6B7A48。
【对比】对比度强，高光不过曝，暗部保留细节，暖光靠冷色阴影托底才有体积感。
写实摄影，4K，无人物，无文字，无水印。
```

API 请求体见 `examples/relight_request.json`（模型 `seedream-5.0`，`reference_images` 放原始照片链接）。外景照片换用外景色卡的色值和"太阳高度 35°–45°"。

### 优化帧必须让用户来选

优化帧决定了整条视频的光和色，属于审美决定，**不能替用户定。没有用户选定的优化帧，不要开始生成视频。**

1. **每张照片出 2–3 个候选**，只在光的强弱和方向上拉开差别，其余提示词不变：
   - 弱光版："阳光柔和，光斑淡，对比度中等"（对应原画布的"衣帽间弱光线"）
   - 标准版：按上面的模板
   - 强光版："阳光强烈，光斑清晰明亮，对比度强"（对应原画布的"修改2"）
2. **拼对比图给用户看**：`scripts/compare.sh 对比.png 原图 候选1 候选2 候选3`，图上自带编号，0 是原图。
3. **请用户逐张选**，可以回"主卧选 2，厨房选 1"。同时问一句全片要不要统一成同一档光。
4. **用户都不满意**：问清要改什么（更暖/更冷、更亮/更暗、光从哪边来），按意见再出一轮，不要自己猜着直接进下一步。
5. **选定后才做视频**，并记下每张照片选了哪一版，后面重跑视频都用同一张。

省钱做法：先拿一两张最有代表性的照片（客厅、主卧）出候选，让用户定下光的强弱档位，其余照片直接按这一档出，再让用户整体过一遍。

### 实测结论

- **有效**：一张正午平光的卧室照片，优化后房间结构、家具、机位完全没变，多了斜射暖阳、地毯上的窗格光斑和墙上的长影子。一张约 0.32。
- **要检查光斑合不合理**：实测结果里天花板上多了一块不该有的光斑。优化帧出来后先看一眼，光斑只应该落在阳光照得到的地方，不对就重跑或加一句"天花板上没有阳光光斑"。
- **不能改房子本身**：只改光和色。优化后要和原始照片对一遍，家具、门窗、窗外景物不能多也不能少。
- 全片所有照片用同一套色值，色调才统一。
- 把色卡做成图片连到视频节点上也可以（原画布的做法），提示词写"光线参考 @外景色卡，下午四点的暖光"。

### 视频里怎么保持住

- 提示词开头的内容要求里可以加："生成视频颜色和首尾帧光照滤镜完全一样"。
- 人出镜时点名光线："光线参考 @色卡"、"光线来自画面右侧"、"人物脸上亮一点"。

## 二点六、人物三视图

原画布里每位经纪人都有一张定妆图，名字叫"经纪人四视图""经纪人定版形象图""最终形象"等，内容都一样：

- **三个全身视图**：正面、侧面、背面，站姿自然，双手垂放。
- **一张脸部特写**：头肩像，表情亲切。
- 纯浅灰影棚背景，柔和均匀的光，同一套服装。

版式有两种，都可以：2×2 方图（三个全身 + 一个特写各占一格），或横版（左边大特写，右边三个全身并排）。

做法：

1. 拿经纪人的真实照片当参考图，用图片模型生成三视图。提示词要点："同一个人、正面/侧面/背面全身 + 头肩特写、浅灰影棚背景、脸和发型和服装在所有视图里一致、无文字"。
2. 反复出几版，挑最像本人的，定稿后改名"定版"，之后全片只用这一张。
3. 换衣服就重做一张新的三视图，不要在视频提示词里用文字改衣服。
4. 有特殊特征要写明，原画布里有一条："人物手心没有纹身，手背有"。
5. 多人出镜时每人一张，角色名和图一一对应（"男主是 @You，同事是 @Colleague 2"）。

注意：三视图是影棚平光，直接用会带来贴片感，所以视频提示词里要写"只参考长相、发型和服装，不参考图里的影棚灯光"（见第六节）。

## 二点七、声音：参考音频，还是克隆

**原画布的做法不是单独克隆，而是把经纪人本人的录音当"参考音频"连到视频节点上**，由视频模型在生成时还原音色和口音。提示词写"声音参考 @音频（保留口音，整条视频音色保持不变）"。画布里的音频来源有三种：直接上传的旁白录音、用"音频剪裁"切出来的小段、从视频里"提取音轨"得到的音频。

按手上有什么来选：

| 手上有的 | 做法 |
|---|---|
| 经纪人念的**整条旁白录音** | 最好。按段剪开，每段当参考音频，台词和录音一致，嘴型最准 |
| 只有经纪人的**一段说话视频** | 先提取音轨，再当参考音频用。台词可以和音频内容不同，模型只借音色 |
| 只有**很短的声音样本**，而旁白是新写的 | 用声音克隆：先克隆出音色，再用它把每段旁白合成出来，合成结果当参考音频 |
| 什么都没有（虚构样片） | 选一个现成音色合成旁白 |

声音克隆在这个 API 里的走法（**流程来自文档，没有实测**）：

1. 提交 `model: minimax_voice_clone`，`file_url` 填经纪人声音样本的公开 MP3 链接，`text` 填一句试听文本。完成后得到一个 `voice_id`。
2. 用 `model: minimax-tts`，`voice_setting.voice_id` 填上一步的 `voice_id`，把每段旁白分别合成。
3. 合成出的每段音频当作对应视频段的参考音频。

克隆声音必须有本人明确授权；克隆出的音色只有所属账号能用。

## 三、整条视频的结构

| 位置 | 内容 | 人出镜 | 空镜 |
|---|---|---|---|
| 开场 | 航拍外景 2–3 秒 → 经纪人从门廊走来说"Welcome to + 地址 + 价格" | 约 8 秒 | 约 3 秒 |
| 外观 | 经纪人站在门口或车库前讲一句 → 门把手、门牌特写 | 约 5 秒 | 约 3 秒 |
| 客厅 / 厨房 | 经纪人摸着台面边走边讲 → 壁炉、台面特写，画外音接着讲 | 约 6 秒 | 约 5 秒 |
| 主卧 / 浴室 | 经纪人站在窗边或衣帽间里讲 → 床头、浴缸特写 | 约 5 秒 | 约 5 秒 |
| 重点卖点 | 经纪人出现在卖点位置上讲（坐在游戏桌前、躺在泳池躺椅上） | 约 6 秒 | 约 3 秒 |
| 结尾 | 经纪人面向镜头说"约看房" → 航拍拉远 | 约 6 秒 | 约 3 秒 |

### 人物出镜占比：要到一半

**规则：人物出镜总秒数 ÷ 全片总秒数 ≥ 50%。** "出镜"指画面里能看清经纪人的时间；只有画外音、人不在画面里的不算；航拍里人很小的也不算。

怎么排到一半：

- **每个空间一个"人 + 景"组合**：先让经纪人在这个空间里出镜讲第一句（4–8 秒），再切 2–3 个空镜特写，由画外音讲完剩下的。不要整段都是空镜。
- **人的镜头和空镜交替**，不要把人全堆在开头和结尾。
- **空镜要短**：每个空镜 2–3 秒，一个空间最多 2–3 个。空镜是"补画面"的，不是主体。
- **台词分配跟着走**：一半以上的台词安排成出镜时说（"张嘴说到"），其余做画外音。
- **人的镜头要有变化**，否则一半时间都是人会单调：换景别（中景、近景）、换动作（走、坐、摸台面、指方向）、换位置，每次出镜不超过 8 秒。

排完后在分段表里加两列算一遍：

| 段 | 总秒数 | 人出镜秒数 |
|---|---|---|
| 1 开场 | 11 | 8 |
| 2 客厅厨房 | 11 | 6 |
| 3 主卧浴室 | 10 | 5 |
| 4 结尾 | 9 | 6 |
| 合计 | 41 | 25（61%） |

不到 50% 就把某段空镜换成人出镜，或缩短空镜。生成后再用 `scripts/review.sh` 的每秒一帧总览图数一遍有人的帧数，按实际成片核对，因为模型不一定严格按秒数执行。

代价要告诉用户：人出镜的片段比空镜更容易出问题（贴片感、口型、长相走样），占比提到一半后，重跑次数和花费会比以空镜为主的做法高。

## 四、参数

- 模式：全能参考（图 + 音频一起参考），开启"生成音频"
- 时长：一个节点 4–15 秒
- 比例：16:9 为主；发短视频平台另做一版 9:16
- 清晰度：720P 打样，定稿再考虑高清

## 四点五、用 API 全自动跑一遍（已实测跑通）

不用画布也能做。下面是用 GlobalStore API 实际跑通一条 39 秒样片的做法，脚本在本目录 `scripts/`，当时用的提示词在 `examples/`。

### 接口要点

- 文档：`https://docs.globalstore.ai/zh`。图片、配音、视频都走同一个接口：
  提交 `POST /kyyReactApiServer/v2/model-center/tasks`，查询 `GET .../tasks/{id}`，余额 `GET /kyyReactApiServer/users/getBalance`。
- 认证：请求头 `Authorization: Bearer <key>`。**密钥只放环境变量 `GLOBALSTORE_API_KEY`，不写进文件、不提交 git。** 用户把密钥明文发在聊天里时，提醒对方用完后去控制台换新的。
- 用到的模型：

| 用途 | model | 关键参数 | 实测单价 |
|---|---|---|---|
| 房间照片、定妆图 | `seedream-5.0` | `aspect_ratio`、`resolution: 2K` | 约 0.32 / 张 |
| 优化帧（图生图改光影） | `seedream-5.0` | 加 `reference_images: [原始照片链接]` | 约 0.32 / 张 |
| 声音克隆（未实测） | `minimax_voice_clone` | `file_url`、`text`、`upstream_model` | 未测 |
| 配音 | `minimax-tts` | `voice_setting.voice_id`、`upstream_model: speech-2.8-hd` | 约 0.01 / 段 |
| 视频 | `sd_2.0_discount` | `reference_images`（最多 9）、`reference_audios`（最多 3）、`duration` 4–15、`resolution` | 约 0.07 / 秒（720p） |

- 参考素材必须是**公开可访问的链接**。前一步生成的图片、音频链接可以直接喂给视频任务。
- 结果链接约 24 小时过期，生成完马上下载。
- 提交时返回的 `amount` 是预扣，比实际高好几倍；实际扣费看任务完成后的 `amount`。
- 单价文档里要登录才看得到，所以**先跑最短的一段测出实际扣费，再批量跑**，每一步后查一次余额。
- 提示词里用"图片1、图片2、音频1"按传入顺序指代素材。

### 操作步骤

```bash
export GLOBALSTORE_API_KEY=...      # 只在当前终端里
SK=.claude/skills/listing-video/scripts
mkdir -p job media

# 1. 生成素材（真实项目跳过这步，直接用房源照片和经纪人素材的公开链接）
python3 $SK/gs.py submit img_living job/img_living.json     # 请求体写法见 examples/asset_requests.json
python3 $SK/gs.py submit vo1 job/vo1.json
python3 $SK/gs.py wait img_living vo1

# 1.5 优化帧：每张房源照片先做光影色彩优化（请求体见 examples/relight_request.json）
python3 $SK/gs.py submit relit_bedroom job/relit_bedroom.json && python3 $SK/gs.py wait relit_bedroom
python3 $SK/gs.py fetch relit_bedroom media/relit_bedroom.jpg   # 下载后和原图对一遍，再用它做视频参考图

# 2. 量一下每段配音多长，决定每段视频的时长
python3 $SK/gs.py fetch vo1 media/vo1.mp3 && ffprobe -v error -show_entries format=duration -of csv=p=0 media/vo1.mp3

# 3. 写提示词到 job/seg1.prompt.txt，拼请求体，提交
python3 $SK/make_video_task.py seg1 13 img_exterior,img_agent vo1
python3 $SK/gs.py submit seg1 job/seg1.json && python3 $SK/gs.py wait seg1

# 4. 下载、看图检查
python3 $SK/gs.py fetch seg1 media/seg1.mp4 && $SK/review.sh media/seg1.mp4

# 5. 拼成片
$SK/stitch.sh listing_video.mp4 media/seg1.mp4 media/seg2.mp4 media/seg3.mp4 media/seg4.mp4
```

### 时长怎么定

- 空镜段：视频时长 = 配音时长向上取整，再加 0–1 秒。
- 出镜段带航拍：视频时长 = 配音时长 + 航拍的 3 秒。
- 定完时长后算人物出镜占比，不到一半就调整（见第三节）。实测那条 39 秒样片人出镜约 16 秒，只有 41%，**不达标**，照这条规则应把客厅、主卧两段各改成"人先出镜讲一句再切空镜"。
- 实测一条 4 段样片：配音 9.9 / 8.1 / 6.1 / 6.3 秒，对应视频 13 / 9 / 7 / 10 秒，合计 39 秒。

### 没有真实素材时怎么做样片

先做一条全虚构的样片给用户看效果，再换真素材。

- 房间照片：6 张同一套风格的图，提示词共用一段"房型 + 光线 + 镜头"的前缀，只换房间描述，保证像同一栋房子。必写 `no people, no text, no watermark`。
- 定妆图：一张 1:1 的四视图，写明"同一个人、2x2 排列、正面/侧面/背面全身 + 头肩特写、浅灰影棚背景"。
- 配音：把旁白切好段，每段单独合成一条，全片用同一个 `voice_id`。数字写成英文单词（"twelve eighty-four"），避免读错。
- 明确告诉用户：样片里的房子、人、地址、价格都是虚构的。

### 成本参考

一条约 40 秒的 4 段样片，含 7 张图、4 段配音、4 段视频各跑 1 次，实际花费约 5 额度。每重跑一段约 0.5–0.9。

### 交付

- 成片先在本地用 `stitch.sh` 拼好。
- 用户说打不开文件时，把视频压到 15MB 以内，连同一个简单的播放页一起发布成网页链接；发不了邮件就直说。
- 交付时必须说明：**画面是逐帧抽查过的，声音没法听**，台词和口型要用户自己确认。

## 五、B 类：空镜片段怎么写

**规则：一张照片拆 2–3 个镜头，先全景后局部，每个镜头 2–3 秒。每个镜头只写四样：哪张图、景别、运镜、画面里什么在动。**

```
【0-3秒】镜头一：@主卧 全景，缓慢向右旋转镜头，风扇在慢慢旋转，白色纱帘被微风吹动
【3-5秒】镜头二：@主卧 特写窗前的绿植，在微风中轻轻摇曳
【5-7秒】镜头三：@主卧 近景床头柜，移镜头
【7-10秒】镜头四：@浴室 全景，向前缓慢推镜头，蜡烛在摇曳
【10-12秒】镜头五：@浴室 特写浴缸冒出的热气
```

要配旁白时，在镜头里加一句：`经纪人的画外音是："……"`，并在开头写 `【角色】经纪人的画外音音频是 @这段配音`。

### 让照片"活起来"的小动作（原项目常用）

| 空间 | 可以动的东西 |
|---|---|
| 卧室 | 吊扇慢转、纱帘飘动、绿植摇曳、空气里的尘埃 |
| 厨房 / 卫生间 | 水龙头流水、浴缸冒热气、花瓣漂浮、蜡烛摇曳 |
| 客厅 | 壁炉火苗、阳光里的尘埃、影子缓慢移动 |
| 外景 | 前景虚化的树叶、光斑透过枝叶、泳池水面波动 |

### 常用运镜

- 全景：缓慢推、缓慢拉、缓慢环绕、向右旋转
- 局部：特写 + 缓慢环绕、俯拍移镜头、变焦（前景虚到后景实）
- 外景：航拍 360° 环绕、超低角度仰拍缓推、低视角上摇、航拍拉远
- 每个镜头都加"缓慢"二字，房源视频忌快

### 特写镜头清单（每个空间至少配一个）

原画布里几乎每张照片都会拆出一个特写，全景交代空间，特写给质感：

| 空间 | 特写拍什么 |
|---|---|
| 外观 | 门把手上的金光、门牌、前景虚化的树叶后面的房子、石子路低角度 |
| 客厅 | 壁炉火苗、吊灯、百叶窗透进来的光、沙发一角、地毯上的光尘 |
| 厨房 | 水龙头流水、台面反光、烤箱和灶台、吧凳 |
| 卧室 | 床头柜和台灯、枕头、窗前绿植的几片叶子、床尾凳、墙上的画 |
| 浴室 | 浴缸热气、蜡烛火焰、洗手池、被风吹动的纱帘 |
| 户外 | 泳池水面、躺椅、花盆叶子上的水珠 |

特写常配的手法：变焦（"前景虚焦处是绿植，后景是灯，然后变焦到绿植"）、缓慢环绕、俯拍移镜头、手持镜头、"镜头要有呼吸感"。

### 光影段（想要高级感时贴在镜头后面）

慢速版，适合室内：

```
光影有极慢速的运动。画面里唯一在变化的是影子：地面上和主体表面的影子以极慢、均匀的速度
缓缓偏转角度、拉长长度，影子的边缘始终保持柔和；被照亮的部分亮度缓慢升高，背光的部分
缓慢变暗，明暗的分界线在地面和墙面上一寸寸地平移。
```

快速流光版，适合开场或高光镜头（原画布原文，用得少，容易闪）：

```
光在独立地高速流动：一道强烈的暖金色光束从画面左上方快速扫入，光斑在墙面和地面上流动、
跳跃；阴影边缘随之快速推移、拉伸、收缩。明亮光斑不断掠过画面前景，形成流动的光晕、眩光
与镜头光斑。体积光在空气中翻涌，尘埃微粒逆光飞舞。镜头运动与光影变化是两套独立的节奏：
镜头缓慢平稳，光影变化明显。侧逆光机位，电影感，高对比度。
```

外景暖光版：

```
暖金色的光带和它的阴影在受光面上缓缓滑过，光束里的微尘慢慢漂浮。曝光锁定在高光，
暗部始终保持深黑，全程不要自动提亮。光的方向从头到尾不变，不要闪烁，
画面内不要有任何灯亮起。
```

## 六、A 类：经纪人出镜片段怎么写

```
【内容要求】人物发丝清晰，皮肤纹理真实细腻。人物光影融入场景图，不是贴图。
保证人物一致性，增强画面颗粒感，4k高清，人物质感真实，无变形、无穿模，
符合现实逻辑。无背景音乐，无字幕。

【角色】经纪人是 @经纪人定妆图，经纪人声音参考 @这段配音（保留口音）
【场景】@房源照片

【0-8秒】镜头一：【画面内容】：@房源照片 前跟镜头，经纪人中景，
经纪人从画面左侧入画，向前走四步站定，太阳光照在经纪人身上，
面带微笑的介绍到："Welcome to 2709 …… This listing is now priced at ……"
说到最后一句时用手指一下身后的房子（镜头随着经纪人向前走而向后倒退）
【8-12秒】镜头二：【画面内容】：@外景照片 全景，缓慢环绕镜头，
经纪人画外音是："……"
```

### 出镜片段的固定套路

- **走几步再站定**：写明"向前走四步站定""倒退两步站定"，镜头写"前跟镜头"。人边走边说最自然。
- **配一个手势**：摸台面、指向身后的房子、摊开双手、侧身指二楼。手势写在台词的具体位置上。
- **进画方向**：写"从画面左侧入画""从右侧的门出来"。
- **光**：写"阳光来自画面左侧，打在经纪人头发上，人物融入光线"，人才不像贴上去的。
- **一个节点里先人后景**：前半段人说话，后半段切空镜接画外音，省一次生成。人的部分要占这个节点时长的一半以上。
- **用道具增加真实感**：坐在游戏桌前整理扑克牌、躺在泳池躺椅上、开着代步车到门口。

### 去掉"贴片感"（实测有效）

人像贴上去的，通常是这四个原因：定妆图是影棚平光，模型把那种光也搬过来了；场景是逆光，人脸却被正面照亮；人和背景一样清晰；人站在正中间不动。对应写法：

- **先看场景图里太阳在哪**，把光写具体："太阳在画面左后方，是逆光。在她的头发边缘和左肩形成暖金色轮廓光，脸部处在柔和的阴影里，由草地和天空的反光照亮。"
- **切断定妆图的光**："经纪人是图片2（只参考长相、发型和服装，不要参考图片2里的影棚灯光和灰色背景）"。
- **禁止补光**："不要影棚式的正面补光，不要美颜打光，脸不能比环境亮。"
- **拉开前后景**："85mm长焦镜头，浅景深，焦点在经纪人脸上，身后的房子轻微虚化。"
- **让人和环境发生关系**："脚下有清晰的接触阴影，影子和树影方向一致""走过树影时斑驳的树影从她身上滑过""微风吹动发梢""泳池水面的波光反射在她的西装上"。
- **加手持感**："手持前跟镜头，带一点自然的轻微晃动，轻微胶片颗粒。"
- **从场景里走出来**：让人从门廊、门口走向镜头，比"从画面左侧入画"更融入。

注意：对场景的限制语只锁"结构和外观"，不要写"不要有任何变化"，否则背景像一张静止的底图，人更像贴的。

### 说话相关

- 出镜说话写"**张嘴说到**"，必要时加"严格根据音频对嘴型，不是画外音"。
- 不出镜写"**画外音是经纪人**"。
- 口音写"**保留口音，整条视频音色保持不变**"。
- 台词用引号原样写进去，长度和秒数匹配（英文约每秒 2–3 个词）。
- 开头想先给画面："前一秒不说话，先展示画面，后两秒才开始说话"。

## 六点五、截帧复用与首尾帧：用一帧好画面去带下一次生成

这一节讲的不是"优化帧"（光影色彩优化见二点五），而是另一招：原画布里的"视频截帧 → 图片标记 → 再连回视频节点"。意思是：**别只靠改文字，把一帧对的画面当成素材喂回去。** 有四种用法：

| 用法 | 怎么做 | 解决什么 |
|---|---|---|
| **截好帧当构图参考** | 从某次生成里截出构图、站位最好的一帧，连回节点，写"构图参考 图片3" | 多跑几次里只有一次站位对，想把它固定下来 |
| **截帧后标记** | 在截出的帧上用红色涂出人该站的位置或镜头路线，写"经纪人站在红色标记处（不保留红色标记线）" | 站位、手的位置、镜头路线总是不对 |
| **首帧锁定** | 把房源照片（或上一段的最后一帧）设成首帧，写"以这张图作为视频的首帧" | 开头必须和照片一模一样；两段之间要接得上 |
| **首尾帧** | 同时给首帧和尾帧，写"图片1作为首帧，图片2作为尾帧，构图保持不变" | 固定机位口播、要求起止画面都确定的镜头 |

截帧用 `scripts/grab_frame.sh`：

```bash
scripts/grab_frame.sh media/seg1.mp4 8 media/good.png       # 截第 8 秒
scripts/grab_frame.sh media/seg1.mp4 last media/tail.png    # 截最后一帧，给下一段当首帧
```

API 里首帧、尾帧是单独的参数（请求体示例见 `examples/aerial_first_frame_request.json`）：

```json
{ "model": "sd_2.0_discount", "prompt": "以这张图作为视频的首帧。航拍……",
  "first_image": "https://…/backyard.jpg", "duration": 4, "generate_audio": false }
```

### 实测结论

- **首帧锁定有效**：结尾航拍原来泳池形状走样，改成"只给后院照片当首帧、单独生成 4 秒航拍"后，第一帧和照片完全一致。4 秒只花约 0.28。
- **照片里看不到的部分还是会被模型编出来**：镜头拉远后露出照片外的区域，泳池被画长了。所以首帧要选**把主体拍全**的照片，或者让镜头少拉一点、改成原地缓慢环绕。
- **首帧图必须是公开链接**。截出来的帧是本地文件，要先传到能公开访问的地方才能用。
- 首帧模式这次是单独使用的（没有同时传参考图和参考音频）；两者能不能混用没有测。
- 带首帧的空镜可以关掉生成音频（`generate_audio: false`），拼接脚本会自动补静音。
- 一段里"人说话 + 航拍"想分开优化时：用场景检测找到切点，把人的部分剪出来，再接上单独生成的航拍。

```bash
# 找镜头切点（输出切换发生的秒数）
ffmpeg -i seg4.mp4 -vf "select='gt(scene,0.3)',showinfo" -an -f null - 2>&1 | grep -o 'pts_time:[0-9.]*'
# 只保留切点之前的部分
ffmpeg -y -i seg4.mp4 -t 6.0 -c:v libx264 -crf 16 -c:a aac seg4_person.mp4
```

## 七、保证"和真房子一样"

房源视频不能把房子拍走样，原项目反复用这些话压住模型：

- "场景完全参考 @图，不要有任何变化"
- "不要出现画面中没有的东西"
- "结构不随意改变"（针对木梁、楼梯这类特征结构，可再连一张原图做对照）
- "白色的门一直都是关着的"（防止模型凭空画出门后的房间）
- "图片上的字体要清晰"（门牌、招牌）
- 用了红色标记图，必须写"不保留红色指示线"

## 八、进阶镜头（可选）

- **无人机穿屋一镜到底**：在照片上画路线，提示词写"我现在是一个无人机，先拍全景，再顺着楼梯的引导线拍摄"或"镜头沿红色指示线快速飞到台球桌上空，变缓，近景环绕"。
- **空房变精装**：多张房间图连在一起，写"一镜到底，画面向右旋转，一开始是空房间，然后软装一点点长出来，再快速旋转到下一个房间，每个画面停留两秒"。
- **结尾引导语**：经纪人坐着面向镜头说"Send me a message for a private tour"，手指屏幕右下角再摊开手。
- **航拍循环**：360° 环绕镜头写"首尾可无缝衔接"。

## 九、出问题先查哪儿

1. **房子被改了** → 一个镜头只引用一张照片；加第七节的限制语。
2. **人像贴图** → 加光的方向描述；让人走动而不是站桩。
3. **嘴不动** → 加"张嘴说到"；确认这段配音连上了，并剪到和片段差不多长。
4. **站位不对** → 做标记图；或从上次生成里截一帧好的当构图参考。
5. **一段里问题多** → 把 15 秒拆成两个短节点（人 4–6 秒一个，空镜一个）分别生成。
6. **人有贴片感** → 按第六节"去掉贴片感"改提示词重跑。实测开场段改善明显；人站在水边、背景很亮的镜头改善有限，需要多跑几次挑。
7. **航拍把房子或泳池的形状改了** → 只在提示词里写"泳池是长方形"压不住（实测无效）。把航拍单独拆成一个节点，用首帧锁定（见六点五节），不要和人物段混在一起；还不行就换成贴地的缓慢环绕，不用航拍。
8. **人入画时间比写的早或晚** → 模型对秒数只是大致遵守，前后差 1 秒属正常，靠剪辑修，不值得重跑。
9. **改了提示词后镜头角度变了，背景里看不到房子** → 在镜头描述里写明"身后是泳池和房子"，把要入镜的东西点名。

### 检查成片的方法

- 每段用 `scripts/review.sh` 出一张"每秒一帧"的总览图，看人物是否一致、场景是否走样、分镜是否到位。
- 觉得可疑的地方再单独截一帧大图看（光的方向、脸的亮度、脚下有没有影子）。
- 用 `ffmpeg -af silencedetect` 可以确认有没有人声停顿，但听不出念得对不对。

## 十、注意事项

- 经纪人的长相和声音只能在本人授权下使用。
- 视频里的房子要和真实房源一致，不要让模型添加不存在的设施或景观，避免误导买家。
- 字幕、音乐、联系方式放到后期剪辑里加，生成时一律写"无背景音乐，无字幕"。
