# Listing Video（房源视频）制作法

这套方法从一个 Shotlab 画布的实拍项目里拆出来，里面做了约 10 条美国房源视频。

一条 listing video 其实只由**两种片段**交替拼成：

- **A. 经纪人出镜片段**：经纪人站在房子里对着镜头说话。用在开场、重点卖点、结尾。
- **B. 空镜片段**：没有人，只拍房子，配经纪人的画外音或不配音。占全片大部分。

做法的核心是：**房源照片直接当场景参考图，一张照片拆成 2–3 个镜头；经纪人用一张定妆图和一段录音"放进"照片里。**

## 一、要准备的素材

| 素材 | 要求 |
|---|---|
| 房源照片 | 每个空间 1–3 张，高清。按空间起名（主卧、浴室、泳池、后院、车库…），方便引用 |
| 经纪人定妆图 | 一张图里放正面、侧面、背面全身 + 脸部特写，灰底，服装固定。全片只用这一张 |
| 经纪人配音 | 经纪人本人念的整条旁白录音 |
| 标记图（按需） | 在照片上用红色涂出"人站哪儿"或"镜头走哪条线" |
| 裁剪图（按需） | 把照片里要特写的局部裁出来 |

## 二、制作流程

1. **写旁白并切段**。整条旁白按房子动线切成 6–8 段，每段 5–15 秒，按顺序编号命名。原项目的切法：
   `1.开头外景 → 2.进门 → 3.室内设施 → 4.主卧浴室衣帽间 → 5.客房/游戏厅 → 6.后院泳池车库 → 7.结尾`
2. **每段配照片**。这段旁白说到哪个空间，就连哪几张照片。
3. **决定每段是 A 还是 B**。一般开场、一两个最大卖点、结尾用 A（人出镜），其余用 B（空镜 + 画外音）。
4. **写分镜提示词，生成**。一个节点出 4–15 秒，里面按秒数分镜头。
5. **反复生成挑最好的**。原项目平均每段跑近 5 次。不满意就复制节点、只改一处再跑。
6. **剪辑**。导出片段按编号拼接，后期加字幕、音乐、片尾联系方式。

## 三、整条视频的结构

| 位置 | 内容 | 片段类型 |
|---|---|---|
| 开场 | 航拍 360° 环绕房子外景 → 经纪人入画说"Welcome to + 地址 + 价格" | B → A |
| 外观 | 门廊、大门、车库等特写，画外音讲卖点 | B |
| 室内 | 客厅、厨房、主卧、浴室、衣帽间，逐个空间 | B 为主 |
| 重点卖点 | 经纪人出现在卖点位置上讲一句（摸着厨房台面、坐在游戏桌前、躺在泳池躺椅上） | A |
| 户外 | 后院、泳池环绕镜头 | B |
| 结尾 | 经纪人面向镜头说"约看房"，接航拍拉远 | A → B |

## 四、参数

- 模式：全能参考（图 + 音频一起参考），开启"生成音频"
- 时长：一个节点 4–15 秒
- 比例：16:9 为主；发短视频平台另做一版 9:16
- 清晰度：720P 打样，定稿再考虑高清

## 四点五、用 API 全自动跑一遍（已实测跑通）

不用画布也能做。下面是用 GlobalStore API 实际跑通一条 39 秒样片的做法，脚本在本目录 `scripts/`，当时用的提示词在 `examples/`。

### 接口要点

- 文档：`https://docs.globalstore.ai/zh`。图片、配音、视频都走同一个接口：
  提交 `POST /kyyReactApiServer/v2/model-center/tasks`，查询 `GET .../tasks/{id}`，余额 `GET /kyyReactApiServer/users/getBalance`。
- 认证：请求头 `Authorization: Bearer <key>`。**密钥只放环境变量 `GLOBALSTORE_API_KEY`，不写进文件、不提交 git。** 用户把密钥明文发在聊天里时，提醒对方用完后去控制台换新的。
- 用到的模型：

| 用途 | model | 关键参数 | 实测单价 |
|---|---|---|---|
| 房间照片、定妆图 | `seedream-5.0` | `aspect_ratio`、`resolution: 2K` | 约 0.32 / 张 |
| 配音 | `minimax-tts` | `voice_setting.voice_id`、`upstream_model: speech-2.8-hd` | 约 0.01 / 段 |
| 视频 | `sd_2.0_discount` | `reference_images`（最多 9）、`reference_audios`（最多 3）、`duration` 4–15、`resolution` | 约 0.07 / 秒（720p） |

- 参考素材必须是**公开可访问的链接**。前一步生成的图片、音频链接可以直接喂给视频任务。
- 结果链接约 24 小时过期，生成完马上下载。
- 提交时返回的 `amount` 是预扣，比实际高好几倍；实际扣费看任务完成后的 `amount`。
- 单价文档里要登录才看得到，所以**先跑最短的一段测出实际扣费，再批量跑**，每一步后查一次余额。
- 提示词里用"图片1、图片2、音频1"按传入顺序指代素材。

### 操作步骤

```bash
export GLOBALSTORE_API_KEY=...      # 只在当前终端里
SK=.claude/skills/listing-video/scripts
mkdir -p job media

# 1. 生成素材（真实项目跳过这步，直接用房源照片和经纪人素材的公开链接）
python3 $SK/gs.py submit img_living job/img_living.json     # 请求体写法见 examples/asset_requests.json
python3 $SK/gs.py submit vo1 job/vo1.json
python3 $SK/gs.py wait img_living vo1

# 2. 量一下每段配音多长，决定每段视频的时长
python3 $SK/gs.py fetch vo1 media/vo1.mp3 && ffprobe -v error -show_entries format=duration -of csv=p=0 media/vo1.mp3

# 3. 写提示词到 job/seg1.prompt.txt，拼请求体，提交
python3 $SK/make_video_task.py seg1 13 img_exterior,img_agent vo1
python3 $SK/gs.py submit seg1 job/seg1.json && python3 $SK/gs.py wait seg1

# 4. 下载、看图检查
python3 $SK/gs.py fetch seg1 media/seg1.mp4 && $SK/review.sh media/seg1.mp4

# 5. 拼成片
$SK/stitch.sh listing_video.mp4 media/seg1.mp4 media/seg2.mp4 media/seg3.mp4 media/seg4.mp4
```

### 时长怎么定

- 空镜段：视频时长 = 配音时长向上取整，再加 0–1 秒。
- 出镜段带航拍：视频时长 = 配音时长 + 航拍的 3 秒。
- 实测一条 4 段样片：配音 9.9 / 8.1 / 6.1 / 6.3 秒，对应视频 13 / 9 / 7 / 10 秒，合计 39 秒。

### 没有真实素材时怎么做样片

先做一条全虚构的样片给用户看效果，再换真素材。

- 房间照片：6 张同一套风格的图，提示词共用一段"房型 + 光线 + 镜头"的前缀，只换房间描述，保证像同一栋房子。必写 `no people, no text, no watermark`。
- 定妆图：一张 1:1 的四视图，写明"同一个人、2x2 排列、正面/侧面/背面全身 + 头肩特写、浅灰影棚背景"。
- 配音：把旁白切好段，每段单独合成一条，全片用同一个 `voice_id`。数字写成英文单词（"twelve eighty-four"），避免读错。
- 明确告诉用户：样片里的房子、人、地址、价格都是虚构的。

### 成本参考

一条约 40 秒的 4 段样片，含 7 张图、4 段配音、4 段视频各跑 1 次，实际花费约 5 额度。每重跑一段约 0.5–0.9。

### 交付

- 成片先在本地用 `stitch.sh` 拼好。
- 用户说打不开文件时，把视频压到 15MB 以内，连同一个简单的播放页一起发布成网页链接；发不了邮件就直说。
- 交付时必须说明：**画面是逐帧抽查过的，声音没法听**，台词和口型要用户自己确认。

## 五、B 类：空镜片段怎么写

**规则：一张照片拆 2–3 个镜头，先全景后局部，每个镜头 2–3 秒。每个镜头只写四样：哪张图、景别、运镜、画面里什么在动。**

```
【0-3秒】镜头一：@主卧 全景，缓慢向右旋转镜头，风扇在慢慢旋转，白色纱帘被微风吹动
【3-5秒】镜头二：@主卧 特写窗前的绿植，在微风中轻轻摇曳
【5-7秒】镜头三：@主卧 近景床头柜，移镜头
【7-10秒】镜头四：@浴室 全景，向前缓慢推镜头，蜡烛在摇曳
【10-12秒】镜头五：@浴室 特写浴缸冒出的热气
```

要配旁白时，在镜头里加一句：`经纪人的画外音是："……"`，并在开头写 `【角色】经纪人的画外音音频是 @这段配音`。

### 让照片"活起来"的小动作（原项目常用）

| 空间 | 可以动的东西 |
|---|---|
| 卧室 | 吊扇慢转、纱帘飘动、绿植摇曳、空气里的尘埃 |
| 厨房 / 卫生间 | 水龙头流水、浴缸冒热气、花瓣漂浮、蜡烛摇曳 |
| 客厅 | 壁炉火苗、阳光里的尘埃、影子缓慢移动 |
| 外景 | 前景虚化的树叶、光斑透过枝叶、泳池水面波动 |

### 常用运镜

- 全景：缓慢推、缓慢拉、缓慢环绕、向右旋转
- 局部：特写 + 缓慢环绕、俯拍移镜头、变焦（前景虚到后景实）
- 外景：航拍 360° 环绕、超低角度仰拍缓推、低视角上摇、航拍拉远
- 每个镜头都加"缓慢"二字，房源视频忌快

### 光影段（想要高级感时贴在镜头后面）

慢速版，适合室内：

```
光影有极慢速的运动。画面里唯一在变化的是影子：地面上和主体表面的影子以极慢、均匀的速度
缓缓偏转角度、拉长长度，影子的边缘始终保持柔和；被照亮的部分亮度缓慢升高，背光的部分
缓慢变暗，明暗的分界线在地面和墙面上一寸寸地平移。
```

外景暖光版：

```
暖金色的光带和它的阴影在受光面上缓缓滑过，光束里的微尘慢慢漂浮。曝光锁定在高光，
暗部始终保持深黑，全程不要自动提亮。光的方向从头到尾不变，不要闪烁，
画面内不要有任何灯亮起。
```

## 六、A 类：经纪人出镜片段怎么写

```
【内容要求】人物发丝清晰，皮肤纹理真实细腻。人物光影融入场景图，不是贴图。
保证人物一致性，增强画面颗粒感，4k高清，人物质感真实，无变形、无穿模，
符合现实逻辑。无背景音乐，无字幕。

【角色】经纪人是 @经纪人定妆图，经纪人声音参考 @这段配音（保留口音）
【场景】@房源照片

【0-8秒】镜头一：【画面内容】：@房源照片 前跟镜头，经纪人中景，
经纪人从画面左侧入画，向前走四步站定，太阳光照在经纪人身上，
面带微笑的介绍到："Welcome to 2709 …… This listing is now priced at ……"
说到最后一句时用手指一下身后的房子（镜头随着经纪人向前走而向后倒退）
【8-12秒】镜头二：【画面内容】：@外景照片 全景，缓慢环绕镜头，
经纪人画外音是："……"
```

### 出镜片段的固定套路

- **走几步再站定**：写明"向前走四步站定""倒退两步站定"，镜头写"前跟镜头"。人边走边说最自然。
- **配一个手势**：摸台面、指向身后的房子、摊开双手、侧身指二楼。手势写在台词的具体位置上。
- **进画方向**：写"从画面左侧入画""从右侧的门出来"。
- **光**：写"阳光来自画面左侧，打在经纪人头发上，人物融入光线"，人才不像贴上去的。
- **一个节点里先人后景**：前半段人说话，后半段切空镜接画外音，省一次生成。
- **用道具增加真实感**：坐在游戏桌前整理扑克牌、躺在泳池躺椅上、开着代步车到门口。

### 去掉"贴片感"（实测有效）

人像贴上去的，通常是这四个原因：定妆图是影棚平光，模型把那种光也搬过来了；场景是逆光，人脸却被正面照亮；人和背景一样清晰；人站在正中间不动。对应写法：

- **先看场景图里太阳在哪**，把光写具体："太阳在画面左后方，是逆光。在她的头发边缘和左肩形成暖金色轮廓光，脸部处在柔和的阴影里，由草地和天空的反光照亮。"
- **切断定妆图的光**："经纪人是图片2（只参考长相、发型和服装，不要参考图片2里的影棚灯光和灰色背景）"。
- **禁止补光**："不要影棚式的正面补光，不要美颜打光，脸不能比环境亮。"
- **拉开前后景**："85mm长焦镜头，浅景深，焦点在经纪人脸上，身后的房子轻微虚化。"
- **让人和环境发生关系**："脚下有清晰的接触阴影，影子和树影方向一致""走过树影时斑驳的树影从她身上滑过""微风吹动发梢""泳池水面的波光反射在她的西装上"。
- **加手持感**："手持前跟镜头，带一点自然的轻微晃动，轻微胶片颗粒。"
- **从场景里走出来**：让人从门廊、门口走向镜头，比"从画面左侧入画"更融入。

注意：对场景的限制语只锁"结构和外观"，不要写"不要有任何变化"，否则背景像一张静止的底图，人更像贴的。

### 说话相关

- 出镜说话写"**张嘴说到**"，必要时加"严格根据音频对嘴型，不是画外音"。
- 不出镜写"**画外音是经纪人**"。
- 口音写"**保留口音，整条视频音色保持不变**"。
- 台词用引号原样写进去，长度和秒数匹配（英文约每秒 2–3 个词）。
- 开头想先给画面："前一秒不说话，先展示画面，后两秒才开始说话"。

## 七、保证"和真房子一样"

房源视频不能把房子拍走样，原项目反复用这些话压住模型：

- "场景完全参考 @图，不要有任何变化"
- "不要出现画面中没有的东西"
- "结构不随意改变"（针对木梁、楼梯这类特征结构，可再连一张原图做对照）
- "白色的门一直都是关着的"（防止模型凭空画出门后的房间）
- "图片上的字体要清晰"（门牌、招牌）
- 用了红色标记图，必须写"不保留红色指示线"

## 八、进阶镜头（可选）

- **无人机穿屋一镜到底**：在照片上画路线，提示词写"我现在是一个无人机，先拍全景，再顺着楼梯的引导线拍摄"或"镜头沿红色指示线快速飞到台球桌上空，变缓，近景环绕"。
- **空房变精装**：多张房间图连在一起，写"一镜到底，画面向右旋转，一开始是空房间，然后软装一点点长出来，再快速旋转到下一个房间，每个画面停留两秒"。
- **结尾引导语**：经纪人坐着面向镜头说"Send me a message for a private tour"，手指屏幕右下角再摊开手。
- **航拍循环**：360° 环绕镜头写"首尾可无缝衔接"。

## 九、出问题先查哪儿

1. **房子被改了** → 一个镜头只引用一张照片；加第七节的限制语。
2. **人像贴图** → 加光的方向描述；让人走动而不是站桩。
3. **嘴不动** → 加"张嘴说到"；确认这段配音连上了，并剪到和片段差不多长。
4. **站位不对** → 做标记图；或从上次生成里截一帧好的当构图参考。
5. **一段里问题多** → 把 15 秒拆成两个短节点（人 4–6 秒一个，空镜一个）分别生成。
6. **人有贴片感** → 按第六节"去掉贴片感"改提示词重跑。实测开场段改善明显；人站在水边、背景很亮的镜头改善有限，需要多跑几次挑。
7. **航拍把房子或泳池的形状改了** → 只在提示词里写"泳池是长方形"压不住（实测无效）。把航拍单独拆成一个节点，只连那一张照片，不要和人物段混在一起；还不行就换成贴地的缓慢环绕，不用航拍。
8. **人入画时间比写的早或晚** → 模型对秒数只是大致遵守，前后差 1 秒属正常，靠剪辑修，不值得重跑。
9. **改了提示词后镜头角度变了，背景里看不到房子** → 在镜头描述里写明"身后是泳池和房子"，把要入镜的东西点名。

### 检查成片的方法

- 每段用 `scripts/review.sh` 出一张"每秒一帧"的总览图，看人物是否一致、场景是否走样、分镜是否到位。
- 觉得可疑的地方再单独截一帧大图看（光的方向、脸的亮度、脚下有没有影子）。
- 用 `ffmpeg -af silencedetect` 可以确认有没有人声停顿，但听不出念得对不对。

## 十、注意事项

- 经纪人的长相和声音只能在本人授权下使用。
- 视频里的房子要和真实房源一致，不要让模型添加不存在的设施或景观，避免误导买家。
- 字幕、音乐、联系方式放到后期剪辑里加，生成时一律写"无背景音乐，无字幕"。

## 目录里的文件

- `scripts/gs.py`：提交任务、等待结果、查余额、下载结果。
- `scripts/make_video_task.py`：把提示词、参考图、参考音频拼成视频任务请求体。
- `scripts/review.sh`：给一段视频出每秒一帧的总览图。
- `scripts/stitch.sh`：按顺序拼接多段视频，统一尺寸和响度。
- `examples/*.prompt.txt`：实测跑通的 4 段提示词（开场出镜、客厅厨房空镜、主卧浴室空镜、结尾出镜），可直接改写套用。
- `examples/asset_requests.json`：生成虚构房间照片、定妆图、配音的请求体示例。

## 十一、交付给用户时的输出格式

1. **素材清单**：还缺哪些照片、定妆图、配音。
2. **分段表**：段号、旁白原文、秒数、用哪几张照片、A 还是 B。
3. **每段完整提示词**：按第五、六节模板写好，素材用 `@素材名` 占位。
4. **参数**：时长、比例、清晰度。
5. **剪辑顺序**和后期要加的东西。
