# 有人版 AI 视频制作法

这套方法是从一个 Shotlab 画布实拍项目里拆出来的（797 个节点、205 个视频节点、共约 978 次生成）。
项目内容是美国房产经纪人的带看 / 口播视频。核心思路一句话：

> **不靠文字描述人和场景，而是把"人、声音、场景、构图"全部做成参考素材喂给模型，文字只负责写"几秒到几秒、拍什么、怎么动、说什么"。**

## 一、整体流程（6 步）

1. **定人物**：给每个出镜的人做一张"四视图"（正面全身、侧面全身、背面全身、脸部特写，纯灰背景，拼成一张图）。定稿后全片只用这一张，不再换。
2. **定声音**：准备一段这个人的真实说话录音（原项目是 5–27 秒）。如果手上只有视频，就先"提取音轨"拿到音频。
3. **拆旁白**：把整条配音按内容切成小段（例如"1.位置和优势 / 2.私人车库 / 3.两室一卫…"），每段 5–15 秒，对应一个视频片段。用"音频剪裁"节点切。
4. **备场景**：每个镜头配一张真实场景图（房子外景、客厅、泳池、办公室…）。需要控制人站哪儿时，在场景图上用色块涂出人的位置，做成"标记图"。
5. **写分镜提示词并生成**：一个视频节点 = 一个 4–15 秒的片段，里面再按秒数分 1–5 个镜头。把上面的素材连到节点上，在提示词里点名引用。
6. **抽卡 + 微调 + 剪辑**：同一节点反复生成（原项目平均每个节点 4.8 次，最多 29 次），不满意就复制节点改一两句再跑。挑好的片段导出，到剪辑软件里拼接、加字幕和音乐。

## 二、素材怎么准备

| 素材 | 做法 | 用途 |
|---|---|---|
| 人物四视图 | 一张图里放正/侧/背全身 + 脸部特写，灰底，服装固定 | 锁住长相、身材、服装 |
| 参考音频 | 本人说话录音；或从视频提取音轨；长的要剪短 | 锁住音色和口音 |
| 场景图 | 真实照片或生成图，一景一张，高清 | 锁住环境，不让模型乱改 |
| 标记图 | 在场景图上用红/蓝/绿色块涂出每个人的位置 | 控制站位和构图 |
| 裁剪图 | 把大图里的道具（宣传册、牌子）单独裁出来 | 让道具特写准确 |
| 视频截帧 | 从上一条生成的视频里截一帧，再当参考图 | 让下一段和上一段接得上 |
| 色卡 | 一张写明主色调的色板（如"午后暖光色卡"） | 统一全片色调 |
| 配角图 | 同事、摄影师、软装团队等各一张 | 多人同框时各自对号入座 |

每次生成一般连 2–3 张图（最多见到 9 张）+ 1 段音频。

## 三、生成参数（原项目的实际设置）

- **模式**：全能参考（多图 + 音频 + 视频一起参考），供应商为豆包系模型；少量竖版镜头用了另一家模型出 2K。
- **时长**：4–15 秒，15 秒用得最多。一个节点里塞多个镜头。
- **比例**：横版 16:9 为主；短视频平台用 9:16。
- **清晰度**：打样统一用 720P（省钱、快），不要一上来就开高清。
- **声音**：开启"生成音频"，让模型直接出带口型的人声。

## 四、提示词模板

固定四块：**内容要求 → 角色 → 场景/位置关系 → 按秒分镜**。直接套用：

```
【内容要求】人物发丝清晰，皮肤纹理真实细腻。人物光影融入场景图，不是贴图。
保证人物一致性，增强画面颗粒感，4k高清，人物质感真实，无变形、无穿模，
符合现实逻辑。无背景音乐，无字幕。

【角色】经纪人是 @人物四视图，声音参考 @参考音频（保留口音）
        同事是 @同事图，摄影师是 @摄影师图
【场景】@场景图
【位置关系】@标记图（生成视频不保留红色标记）

【0-4秒】镜头一：【画面内容】（场景完全参考 @场景图，不要有任何变化）
  全景，经纪人从画面左侧入画，站定后面向镜头，张嘴说到："第一句台词"
  【镜头】全景，平拍，缓慢推镜头
【4-9秒】镜头二：【画面内容】近景，经纪人侧面，边走边介绍，
  画外音是经纪人："第二句台词"
  【镜头】近景，跟镜头
【9-12秒】镜头三：【画面内容】特写 @道具裁剪图，画面中不要出现经纪人
  【镜头】特写，俯拍，缓推
```

### 每一块怎么写

- **内容要求**：每条提示词开头都原样贴这一段，不用改。"无背景音乐，无字幕"一定要有——音乐和字幕留到后期自己加。
- **角色**：一句话一个人，格式是"谁 是 哪张图，声音参考 哪段音频"。
- **分镜**：每个镜头写清 4 件事——**景别**（大全景/全景/中景/近景/特写）、**角度**（平拍/俯拍/仰拍）、**运镜**（推/拉/摇/移/跟/环绕/固定）、**人在干什么说什么**。
- **台词**：用引号把原话写进去，台词语言和参考音频一致。台词长度要和秒数匹配（英文大约每秒 2–3 个词）。

## 五、从原项目里总结出的实用技巧

**人物和声音**
- 人出镜说话写"**张嘴说到**""一定要张嘴说话"，否则模型常常只出声不动嘴。
- 人不出镜只有声音写"**画外音是经纪人：…**"，并补一句"画面中不要出现经纪人"。
- 想保留本人口音，写"**保留口音**"或"音调和语速与 @音频 一模一样"。
- 多人说话时，每个人各配一段自己的参考音频，分别写明。

**场景和构图**
- 不想让模型改场景，写"**场景完全参考 @图，不要有任何变化**"。
- 用了标记图，必须补一句"**不保留红色标记线**"，不然色块会出现在成片里。
- 人物进出画面写明方向："从画面左侧入画"。
- 写清人在画面哪里："在画面左三分线上，微微面向画面右侧"。
- 左右手容易错，要用画面方位说清："画面左侧的手拿着手机贴在右耳上"。

**节奏**
- 开头想先给画面再说话："前一秒不说话，先展示画面，后两秒才开始说话"。
- 说完话留个尾巴："说完话之后画面缓慢移到窗外的空镜"。
- 航拍环绕想循环播放："首尾可无缝衔接"。

**光影（让画面不像 AI）**
- "曝光锁定在高光，暗部始终保持深黑，全程不要自动提亮"
- "光的方向从头到尾不变，不要闪烁，画面内不要有任何灯亮起"
- "光束里的微尘慢慢漂浮"、"暖金色光带在受光面上缓缓滑过"
- 全片统一色调：把色卡图连上，并写"暖琥珀色电影调色"之类的话。

**特殊镜头**
- 延时/瞬移效果："固定机位，全程无运镜、无切换。人物以定格跳切的'瞬移'方式变换位置，每跳一次光线明显变化，仿佛几个小时过去。"
- 纯空镜（没人）可以不写内容要求，直接"0-3秒，@图 客厅全景，缓慢向前推镜头"。

## 六、调试顺序（出问题先查哪儿）

1. **脸不像** → 检查是否连了四视图；提示词里是否点名引用了它；参考图是不是太多把人物冲淡了（先减到 2–3 张）。
2. **嘴不动 / 声音不对** → 加"张嘴说到"；检查音频是否连上；音频太长就剪到和片段差不多长。
3. **场景被改了** → 加"完全参考…不要有任何变化"；一个镜头只引用一张场景图。
4. **站位不对** → 做标记图；或者从上一次生成里截一帧好的画面当构图参考。
5. **一段里问题太多** → 把 15 秒拆成两个短节点（比如 4 秒 + 10 秒）分别生成，后期再拼。
6. **改动原则**：每次只改一处，用"复制节点"保留旧版本，方便对比。

## 七、注意事项

- **肖像和声音授权**：这套方法能高度还原真人的长相和声音。只给本人或已取得书面授权的人做；不要拿它去仿冒他人。
- **打样省钱**：先 720P 抽卡，定稿后再考虑高清重跑或后期放大。
- **不要指望一次成片**：原项目平均每个片段跑近 5 次，预算和时间按这个算。
- **原画布里的一个未解细节**：很多节点还连了一段 2 秒的纯黑无声视频（名叫"黑"），但提示词里基本没有引用它，作用没能确认，所以这里没有把它列为必需步骤。

## 八、交付给用户时的输出格式

用户让你帮忙做一条有人版视频时，按这个顺序给：

1. **素材清单**：需要用户准备哪些图和音频（按第二节的表）。
2. **分段表**：整条旁白切成几段、每段几秒、对应哪个场景。
3. **每段的完整提示词**：按第四节模板写好，素材位置用 `@素材名` 占位。
4. **参数**：时长、比例、清晰度。
5. **后期提示**：拼接顺序、哪里加字幕和音乐。
